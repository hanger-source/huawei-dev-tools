# 响应式断点定义

**本文件是断点值的唯一来源**（横向 320/600/840/1440，纵向 0.8/1.2）。断点面向窗口而非设备类型：相同断点区间的窗口展示相同的页面布局。

## 设计原则

- 两个宽度相近的窗口，页面布局相同，断点归一。
- 高度相对宽度较小的窗口（横向/类方形窗口），页面布局差异化设计，引入纵向断点。

## 断点分类

### 1. 横向断点

以应用窗口宽度（vp）为判断条件：

| 断点名称 | 窗口宽度（vp） | 描述 | 典型设备类型 |
|---------|---------------|------|-------------|
| xs | (0, 320) | 超小屏幕 | 智能穿戴设备 |
| sm | [320, 600) | 小屏幕 | 手机竖屏 |
| md | [600, 840) | 中等屏幕 | 折叠屏展开态 |
| lg | [840, 1440) | 大屏幕 | 平板、智慧屏 |
| xl | [1440, +∞) | 超大屏幕 | 电脑 |

> 1. 区间**左闭右开** `[minWidth, maxWidth)`，xs 为 `(0, 320)`。
> 2. 同一设备的不同窗口形态（全屏、分屏、自由窗口）可能落入不同断点区间。
> 3. 确定页面不会在智能穿戴设备上显示时，可不适配 xs。

### 2. 纵向断点

以应用窗口高宽比为判断条件：

| 断点名称 | 高宽比 | 描述 | 典型场景 |
|---------|-------|------|---------|
| sm | (0, 0.8) | 横向窗口 | 平板横屏、电脑 |
| md | [0.8, 1.2) | 类方形窗口 | 折叠屏展开态 |
| lg | [1.2, +∞) | 纵向窗口 | 手机竖屏 |

## DSL 断点配置格式

每个断点一条 `BreakpointConfig`（`minWidth`/`maxWidth` 必填，xl 的 `maxWidth` 为 `null`）；其余断点同构，仅改 `name`/`minWidth`/`maxWidth`：

```json
{
  "name": "sm",
  "minWidth": 320,
  "maxWidth": 600,
  "layoutAdjustments": {
    "columns": 4,
    "direction": "column",
    "gap": 10,
    "margin": 16,
    "padding": 16
  }
}
```

组件级调整通过节点 `responsive.breakpointOverrides` 按断点名称指定，不使用整表式的 `componentAdjustments`。

## 断点适配规则

### 布局方向切换

| 屏幕分类 | 横向断点 | 纵向断点条件 | 推荐布局方向 |
|---------|---------|------------|------------|
| 超小屏 | xs | - | column（垂直） |
| 小屏 | sm | 纵向断点为lg | column（垂直） |
| 小屏横向 | sm | 纵向断点为sm | row（水平） |
| 类方形窗口 | sm | 纵向断点为md | 视组件数量决定 |
| 中屏 | md | - | row（水平） |
| 大屏 | lg | - | row（水平） |
| 超大屏 | xl | - | row（水平） |

### 网格列数适配

| 设计稿列数 | xs | sm | md | lg | xl |
|-----------|-----|-----|-----|-----|-----|
| 2列 | 1列 | 2列 | 2列 | 3列 | 4列 |
| 3列 | 2列 | 2列 | 3列 | 4列 | 5列 |
| 4列 | 2列 | 3列 | 4列 | 6列 | 8列 |
| 5列 | 2列 | 3列 | 4列 | 7列 | 10列 |

## 注意事项

1. 断点区间互不重叠，左闭右开 `[minWidth, maxWidth)`，xs 为 `(0, 320)`
2. 宽度、尺寸、间距单位统一 vp，字体 fp；用户修改显示缩放会改变 vp 值，从而影响断点区间
3. 断点面向窗口而非设备；仅用横向断点无法区分时（如手机横屏与折叠屏展开态），结合纵向断点判断
