# 目标页面数据理解

## 数据来源与模型

- 从页面绑定字段追踪实际 interface、class、enum 和数据源；记录字段类型、含义、默认值与可空约束。
- 区分静态资源、路由参数、服务结果、本地存储和派生值；未知来源明确标注。
- 记录已有数据源的加载、刷新、分页与更新接口，以及列表或组件的消费方式。

## 响应式与生命周期

- 查明数据由哪个组件或服务持有、如何触发 UI 更新，以及跨页面共享范围。
- 检查加载、空、错误和重试状态；记录订阅、请求及临时数据的清理时机。
- 仅追踪本页面实际使用的存储读写接口，不展开无关数据库、实体关系或持久化方案设计。

## 输出检查

将页面字段映射到已有模型和调用位置，说明可复用模型、需要增加的字段和缺失数据源。保持原有参数与字段语义，避免生成重复模型和数据访问层。
