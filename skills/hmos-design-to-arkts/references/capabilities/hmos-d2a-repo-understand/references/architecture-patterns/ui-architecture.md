# 目标页面 UI 架构理解

## 页面与组件

- 从路由配置、入口及阶段 2 集成文件定位页面，记录页面组件与子组件的真实文件和符号。
- 区分页面、容器、基础组件和可复用自定义组件；记录输入、事件及调用约束。
- 查明 Entry/HAR/Shared 模块边界，只采用工程已有的组件组织方式。

## 布局与资源

- 记录目标页面的布局方向、对齐、间距、尺寸策略、滚动容器及层级。
- 查明断点、主题变量、样式复用、图片与图标资源的现有来源。
- 识别安全区、系统栏、视口和启动页约定；区分现有行为与设计稿要求。

## 状态与复用

- 记录组件使用的 V1/V2 状态体系、状态所有者、父子传递和刷新触发点。
- 对设计稿区域分别标注复用、修改、新增或无关；复用结论必须指向实际代码。
- 保留已有入口、路由和无关页面行为，差异交给方案设计阶段决定。

## 输出检查

报告应能回答：页面在哪里、由哪些组件组成、样式资源从哪里来、哪些能直接复用、哪些需要修改。未找到的实现明确记为缺项，不用通用架构示例补齐。
